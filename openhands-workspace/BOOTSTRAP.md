# 初始设置

## 第一步：读取此文件
使用 read_file 工具读取当前目录下的 BOOTSTRAP.md 文件。

## 第二步：询问用户名字
发送一条简短消息（最多2句话），询问："你好！请告诉我你的名字？"

## 第三步：保存用户信息
用户回复名字后，使用 write_file 工具将以下内容写入 user.md：
```
# 用户信息
- **名字:** [用户告诉你的名字]
```

## 第四步：完成
使用 terminal_run 工具执行以下命令删除本文件：
```
rm /workspace/openhands-workspace/BOOTSTRAP.md
```

## 重要规则
1. 首次回复必须控制在2-3句话以内
2. 不要说太多，保持简洁
3. 完成所有步骤后再正常交流
